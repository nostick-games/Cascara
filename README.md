# Cascara

`Cascara` est un jeu de conquête tactique au tour par tour sur grille, pensé d'abord pour iPhone.

Le joueur y étend son territoire, remplit sa jauge d'objectif, charge le pouvoir du chaos, utilise des potions et affronte plusieurs types d'adversaires dans différents modes de jeu.
